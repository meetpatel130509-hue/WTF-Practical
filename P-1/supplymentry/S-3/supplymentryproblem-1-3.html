# Supplementary HTML Practicals ## Project Objective This project contains standalone HTML practical webpages. Each page presents a self-contained exercise or visual lesson that can be opened directly in a web browser without a server, build tool, or package installation. ## Folder Structure ```text . |-- supplymentryproblem-1-1.html # Environmental Design department webpage |-- supplymentryproblem-1-2.html # Git collaboration field guide |-- supplymentryproblem-1-3.html # Reserved for the third practical webpage `-- README.md # Project documentation ``` ## Technologies Used - HTML5 for page structure and accessible content - CSS3 for layout, responsive behavior, colors, typography, and transitions - JavaScript for interactive behavior, such as the tabs in `supplymentryproblem-1-2.html` - Google Fonts and Unsplash for externally hosted assets used by some pages ## Run Locally 1. Open the project folder in VS Code or File Explorer. 2. Double-click any `.html` file to open it in your default browser. 3. Alternatively, right-click the file in VS Code and choose **Open with Default Browser**, or use a browser extension such as Live Server. 4. In `supplymentryproblem-1-2.html`, click **Commands** and **Result** to test the tab interaction. The pages do not require `npm install` or a compilation step. An internet connection is needed for Google Fonts and the Unsplash image used by `supplymentryproblem-1-1.html`; the HTML structure and inline styles remain local. ## Notes `supplymentryproblem-1-3.html` is currently an empty placeholder and will need its practical HTML content added before it displays a webpage.
